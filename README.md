# Hi there, I'm Daddelgreis 👋

Hardware tinkerer, IoT enthusiast, and software developer. Building self-hosted ecosystems, smart home dashboards, and desktop suites for lab equipment.

---

### 🏠 Smart Home & Streaming Ecosystem
* **[smart-home-dashboard](https://github.com/Daddelgreis74/smart-home-dashboard)** — Modern, highly customizable smart home wall panel with J.A.R.V.I.S. AI, multi-theme engine & TrueNAS SCALE support.
* **[smarthome-kiosk](https://github.com/Daddelgreis74/smarthome-kiosk)** — Optimized Android kiosk app for the dashboard with J.A.R.V.I.S. voice assistant support.
* **[smarthome-kiosk-windows](https://github.com/Daddelgreis74/smarthome-kiosk-windows)** — Lightweight Windows Kiosk application (WPF, WebView2, Watchdog, Standby).
* **[rtsp-stream-hub](https://github.com/Daddelgreis74/rtsp-stream-hub)** — High-Performance RTSP, ONVIF & Webcam Stream Hub with on-the-fly MJPEG transcoding & hardware acceleration.

### ⚡ FNIRSI Lab Equipment & Reverse Engineering
* **[fnirsi-firmware-tools](https://github.com/Daddelgreis74/fnirsi-firmware-tools)** — Reverse engineering toolkit, German localization patcher & boot logo injector for FNIRSI devices (DWS-200, IPS-3608, HS-02A).
* **[fnirsi-ips3608-studio](https://github.com/Daddelgreis74/fnirsi-ips3608-studio)** — Professional Windows Desktop Studio & Control Suite for FNIRSI IPS3608 Power Supply.
* **[fnirsi-2c23t-studio](https://github.com/Daddelgreis74/fnirsi-2c23t-studio)** — Desktop Studio & Control Suite for the FNIRSI 2C23T Handheld Oscilloscope.

### 🌐 IoT, Embedded & Mobile
